# dsh-yu-mood ｜ 鱼的心情

她会自己判断情绪，你看得见。

每轮聊完自动判断涨跌，右下角挂饰点开看数值、情绪和时间线；**心情会不会说出口、说到什么程度、门槛多高，全在设置里**。

---

## 它做什么

两件事：

1. **记账**：每轮聊完，用一次模型调用判断这一轮让她心情升了还是降了，写进 `~/.dsh/feiyu-mood/state.json`。
2. **说给她听**：按你的设置，把「现在的心情」注入到**正在说话的那间会话**的系统提示里，让她这一轮的语气跟着变。

它**不参与生成正文**。正文还是主会话写的，它只提供一句背景。

---

## 安装

```powershell
dsh plugin --profile desktop add github:Speraymer/dsh-yu-mood
```

装完重启 DSH。默认就开着判断，但注入方式可以按需调。

---

## 第一次使用

1. **填两个称呼**：设置页第一栏「有心情的那位叫什么」「跟它说话的那位叫什么」。默认是「伙伴 / 对方」，改过才不会把名字串成别人的。
2. **先看几轮**：聊三四轮，点右下角挂饰看时间线，确认判断方向没错。
3. **再决定说不说**：默认「说它刚才那件事」；嫌吵就改成「只说心情」或者「不告诉」。

---

## 设置项

| 字段 | 默认 | 说明 |
|---|---|---|
| 它叫什么 | `伙伴` | 判断时用来区分「谁在说话」 |
| 对方叫什么 | `对方` | 同上 |
| 它平时被叫的别名 | 空 | 逗号分隔。这些词出现在句子里算「在叫它」，不是名词的一部分 |
| 判断用 provider | 空 | 留空 = 跟着当前会话的模型 |
| 判断用 model | 空 | 留空 = 跟着当前会话 |
| 基准心情 | `70` | 平复后回到的位置 |
| 心情下限 | `0` | |
| 半衰期（小时） | `12` | 12 小时 = 隔一夜还留点余温 |
| 怎么告诉它 | `event` | `off` 不说 / `label` 只说心情 / `event` 说底子 + 是什么事 |
| 可信度门槛 | `60` | 低于它只记账，不进她的嘴 |
| 显著·心情 | `3` | 总心情涨跌够这个数才算「有事」（心情实际只吃 1/3，原始值门槛） |
| 显著·单维 | `5` | 或者某一维够这个数（心疼 +5、担心 +5 这种「突然一下」） |
| 每天最多注入 | `6` 次 | 先到先得。门槛调低后靠它防「变背景音」 |
| 自动判断 | 开 | 关掉就只能手动点 |

**七个维度**：开心、平静、甜、心疼、担心、难过、吃醋（`happy / calm / sweet / heartache / worry / sad / jealous`）。

## 运行机制

**判断**：取这一轮的最后一段对话，交出去问一次模型「涨了还是跌了、哪几维动了」。只问方向，不让它写正文。

**写入打折**：模型给的原始涨跌**先除以 3 再写进状态**。实测模型平时就给 +1~+3，不打折几天就贴顶，那时候「心情」就没有信息量了。

**平复**：按 12 小时半衰期往回走，一次波动会慢慢拉回基准线。

**注入**：走 `systemPrompt.context` —— 系统提示里单独的一段，**不是改系统提示本身**。这样 DSH 的前缀缓存不受影响，聊得再久也不会因为它多花钱。

**分房间**：默认按会话分房，各房间互不影响；也有一间共享的底子。

**挂饰**：右下角小鲸鱼点开是数值、情绪名和最近的时间线（含每次判定的理由）。

---

## 边界与已知限制

- **它只判断方向，不自创剧情**：不会因为「今天心情好」就改变她说什么内容。
- **可信度不够就闭嘴**：低于门槛只记后台，这段时间你在界面上看不到变化，但账还在。
- **每会话每天最多注入 6 次**：超了当天就不再提，避免变成背景音。
- **判断要花一次模型调用**：每轮一次。嫌贵可以把「自动判断」关掉，手动点。
- **不改人格文件**：`AGENTS.md` 它一个字都不动。

---

## 依赖与降级

- 拿不到模型（没 key、网关挂了）时，这一轮不判断，只记一条失败日志，不影响你聊天。
- 没有设置服务时退回读 `config.json`。
- 不依赖其他插件。
